# Local updates

The reader checks recent public coverage and opens its source before sharing a link.

Use the existing cream background, green text, serif headings, and 48px controls. Use a chronological list with separators. Avoid crime totals, score cards, decorative charts, and urgency colours.

Show the source, publication date, geographic scope, and unknown incident date. Keep manually checked official coverage separate from the automated news feed. State the research check date. Do not label recent coverage as trending without measured engagement.

Use the earlier Mobbin research at https://mobbin.com/discover/apps/ios/popular as the workflow reference. Transfer source-first detail and clear list navigation. Do not copy branding.

The daily refresh status precedes the list. Show the last attempt and last success. Failed refreshes retain dated records and show stale status. An empty list does not mean no incidents occurred.

On phones, filters wrap and entries occupy one column. Desktop uses the same readable list with source status beside it. All links and buttons have visible focus. Copy confirms only after clipboard success. Sharing requires an explicit button press.

Verify loading, empty, unavailable, stale, success, area filtering, clipboard failure, and keyboard access. Inspect widths of 320px, 390px, and 1440px.
