# Public repository delivery

The supplied repository is `karanmrn/Neighbourhoodwatch`.
Its original main commit and Apache license are preserved.

The local integration history includes review-required acquisition evidence.
That history must not be pushed to the public repository.
The public delivery branch starts from the existing remote main commit.
It contains application code, synthetic fixtures, tests, and public-safe documentation.
It excludes `research/acquisition/`, raw live-probe JSON, credentials, local databases, and browser traces.

Local acquisition evidence remains available in the original workspace.
Source metadata used in the interface is separate from raw acquisition documents.
The application never publishes Context.dev extraction automatically.

Vercel configuration is prepared. No hosted deployment is authorised or verified yet.
The public branch is a reviewable build, not approval for real community intake.
